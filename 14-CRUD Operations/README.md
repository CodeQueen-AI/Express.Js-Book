# 📘 CRUD Operations in Express.js

## 🔹 What Are CRUD Operations?

CRUD ka matlab hota hai **Create, Read, Update, Delete**.
Ye wo basic operations hain jo kisi bhi web application ke **data** ke sath perform kiye jaate hain.
Har real-world project (like social media apps, e-commerce sites, etc.) mei CRUD operations use hote hain.



## 🔹 1. CREATE (POST)

Iska use **naya data add karne** ke liye hota hai.
Example: Jab user signup karta hai ya koi naya item add hota hai — tab *POST request* use hoti hai.



## 🔹 2. READ (GET)

Iska use **data read ya fetch karne** ke liye hota hai.
Example: Jab user apni profile ya products list dekhna chahta hai — tab *GET request* use hoti hai.



## 🔹 3. UPDATE (PUT)

Iska use **existing data update** karne ke liye hota hai.
Example: Jab user apna name ya password change karta hai — tab *PUT request* use hoti hai.



## 🔹 4. DELETE (DELETE)

Iska use **data delete** karne ke liye hota hai.
Example: Jab user apna account ya koi record delete karta hai — tab *DELETE request* use hoti hai.

---

## 🔹 Why CRUD Is Important

CRUD operations har backend project ka **foundation** hote hain.
Ye ensure karte hain ke application data ke sath properly kaam kare —
chahe wo database ho ya API.

---

## 🔹 In Real Projects

Real-time applications mei CRUD operations:

* Database (like MongoDB, MySQL) ke sath connect hote hain.
* Error handling aur validation add hoti hai.
* Authentication (login system) ke sath secure kiye jaate hain.
* Frontend ke sath connect karke user-friendly experience banaya jaata hai.
