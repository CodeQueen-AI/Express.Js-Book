# 📘 Authorization in Express.js

## 🔹 What Is Authorization?

Authorization ka matlab hota hai **ye check karna ke user ko kis action ki permission hai**.
Ye step **authentication ke baad** aata hai — jab user verify ho chuka hota hai.

**Simple words mein:**

> Authorization decide karta hai ke user **kya kar sakta hai** aur **kya nahi**.

---

## 🔹 How Authorization Works

1. **User login karta hai** (Authentication complete hoti hai).
2. Server us user ka **role check karta hai** (jaise admin, user, guest).
3. Agar user ke paas proper access hai to server usse **route ya data access** karne deta hai.
4. Agar permission nahi hai to server **“Access Denied”** message deta hai.

---

## 🔹 Why Authorization Is Important

* Ye system ko **secure** banata hai
* Sirf **authorized users** hi important actions kar sakte hain
* **Data protection** aur **access control** maintain hota hai
* Har user ke liye **different roles** handle karna easy hota hai

---

## 🔹 Common Types of Authorization

1. **Role-based Authorization (RBAC)**

   * Access based on roles like `admin`, `editor`, `user`
   * Example: sirf admin users delete kar sakte hain

2. **Permission-based Authorization**

   * Har action ke liye specific permission set hoti hai
   * Example: edit, read, delete, create

3. **Token-based Authorization (JWT)**

   * Tokens verify karte hain ke user authorized hai ya nahi
   * Mostly APIs aur modern apps mein use hota hai

---

## 🔹 Real-World Example

* **Admin** → User delete kar sakta hai
* **User** → Sirf apna profile dekh sakta hai
* **Guest** → Sirf public pages dekh sakta hai
